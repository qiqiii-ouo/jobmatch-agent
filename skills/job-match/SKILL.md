# 求职匹配技能（JobMatch）

## 何时使用
- 用户给出一段「岗位招聘要求（JD）」+ 自己的「简历」，希望知道匹配怎么样、怎么改。
- 用户准备面试，想要针对岗位的预测题。

## 工作流程
1. 读取并解析 JD 与简历文本。
2. 提取 JD 中的硬性要求（学历、专业、技能、经验）与软性要求（能力关键词）。
3. 提取简历中的对应信息，计算关键词重叠率作为匹配度基线。
4. 找出「JD 要求但简历缺失/偏弱」的点，给出**具体改写示例**（不虚构经历）。
5. 基于岗位要求预测 3 道高频面试题。
6. 按 Persona 的输出格式结构化返回。

## 命令行版（可复现）
仓库内 `jobmatch.py` 提供纯标准库实现，无需 API Key 即可运行：
```bash
python jobmatch.py --jd jd.txt --resume resume.txt
```
设置 `OPENAI_API_KEY` 后加 `--llm` 可调用大模型生成更自然的建议。

## 设计要点（用于面试讲解）
- **提示词工程**：Persona 限定角色、约束、输出格式，保证稳定可控。
- **工具调用**：脚本作为「读取文件 + 提取 + 计算」的工具，由 Agent 编排。
- **记忆**：可缓存用户简历画像 `profile.json`，避免重复输入。
- **RAG（预留）**：岗位库 / 简历库可向量化后检索增强。
