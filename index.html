求职小助手 Agent（JobMatch Agent）

Python · 纯标准库规则引擎 + 可选 LLM · 已开源 · github.com/qiqiii-ouo/jobmatch-agent

输入一份岗位 JD + 你的简历，输出：匹配度评分、简历优化建议、面试题预测。 底层覆盖 Agent 三大件，正好对应我的学习路线 L1→L5。

系统提示词 Persona（L1）persona.md 定义"资深求职顾问"人设、约束与输出格式
工具调用 Tool Use（L2）技能 SKILL.md 可在 WorkBuddy 直接加载调用
记忆 Memory保存简历画像 profile.json，跨轮复用避免重复输入
自写代码 L5jobmatch.py 纯标准库实现，规则基线无需任何 API Key
JD 文本 ─┐
├─► jobmatch.py ─► [提取关键词/技能] ─► [匹配计算] ─► 报告
简历文本 ─┘ ├─ 匹配度评分
├─ 简历优化建议
└─ 面试题准备
（可选）LLM 增强：设置 OPENAI_API_KEY 后调用
▶ 运行演示（终端打字动画） 真实运行 jobmatch.py：输入 JD + 简历 → 输出匹配度 / 优化建议 / 面试题预测

面试怎么讲：从"为什么做"（求职场景痛点）→"Agent 三件套怎么落地" （提示词/工具/记忆）→"规则基线为何免 API Key"（工程取舍）→"下一步 L3 MCP / L4 自动化 / RAG"。 能讲清设计，比只会调 API 更有料。

实战样例 · JobMatch Agent 输出演示

下面是一份真实运行样例：输入通用「应届 AI 产品岗」JD + 我的简历，Agent 自动产出匹配度评分、待补强项与改写建议、面试题预测。用自己简历做 dogfooding，既演示能力也验证可用性。

匹配度评分（Agent 自动输出）

输入：通用「应届 AI 产品运营 / AI 产品经理」JD + 简历
AI 产品运营（应届）82 / 100
高度契合，简历近乎量身打造
AI 产品经理（应届）74 / 100
基本契合，需补 PRD/方法论/取数

Agent 总结的优势：真实 AIGC 实习 + 个人 Agent 开源项目 + 数据驱动 + 用户/增长体感，是应届里很少见的组合。

Agent 自动识别的「待补强项 + 改写建议」（演示工具核心能力）：

① 量化成果偏软多处"显著提升"无数字 → 工具提示替换为真实数据
② 求职意向过宽"运营/产品"定位 → 工具建议主攻一个方向收口
③ 硬技能空白缺 SQL / PRD / 原型工具 → 工具提示补强
④ Agent 项目偏描述缺工具/效果数据 → 工具提示补充量化
